## Goal
Keep the UX as data (ADR-0004): page states, button modes, knob map, key map and help text compile from docs/design/*.tsv into a generated header, so a workflow change is a TSV edit.

## Read first
- docs/design/page_states.tsv, button_modes.tsv, knob_map.tsv, key_map.tsv, help_text.tsv (columns and ids)
- tests/design/gen_help.py, check_help.py (existing TSV readers to reuse)
- build.sh/build.py (where build/gen headers are produced, e.g. felucca_tables.h)

## Deliverable
- tools/gen_ui_tables.py: reads the five TSVs, writes build/gen/ui_tables.h with `static const` arrays and enums (page ids, control ids, label strings, help strings); fails with a clear message on an unknown id or a label over its width in tests/design/widths.tsv
- build.sh runs it before compiling; tests/run_tests.sh runs it; tests/ui_tables_test.c checks row counts against the TSV line counts

## Acceptance criteria
- [ ] `python3 tools/gen_ui_tables.py --check` exits 0
- [ ] build/gen/ui_tables.h is regenerated by ./build.sh
- [ ] ui_tables_test passes
- [ ] `sh tools/check.sh` ends with `CHECK PASS` (the known failures listed in CLAUDE.md are not regressions)
- [ ] The build line `image ... RAM .data+.bss N of 73728; pool ...` is pasted into the Log; RAM headroom (73728 - N) is at least 8192 B, else stop and file an FB (E9 trigger)
